# Повна генерація друкованих розкладів

Весь вміст кожного PNG — заголовки, текст клітинок, сітка, значки та декор — створено вбудованим `image_gen.imagegen`. Назва ліцею, «Розклад уроків», клас і семестр відцентровані над таблицею. Це цілісні згенеровані зображення; програмного накладання таблиці чи тексту немає.

`class-N-prompt.txt` — точні початкові запити з усіма 35 клітинками. Окремі edit-файли містять запити до ImageGen для очищення зайвих декоративних написів та уточнення значків. Після кожного редагування таблиці перевірялися повторно.

`class-N-review.json` — запис візуальної перевірки заголовків, орфографії, 35 клітинок і семи часів. Перевірку тексту виконував Codex на фактичному зображенні. Порівняння контрольних сум перевіряє цілісність прийнятого PNG, а не самостійно розпізнає чи доводить правильність його тексту.

Оригінальні PNG копіюються з результату ImageGen без змін. Нативні розміри вказані в маніфесті. PDF містять лише ці зображення, пропорційно вписані без обрізання із безпечними полями щонайменше 5 мм. Сторінки друку показують WebP-прев’ю та дають завантажити PDF або PNG з такими самими полями; оригінал доступний окремо.
