# Загальний тиждень для друку

П’ять повністю згенерованих ImageGen сторінок містять усі 5–11 класи, по одному дню на аркуші. Текст, сітка, значки й рамка створені разом у зображенні.

Стиль колекції — navy/ivory/gold, центрований компактний заголовок, вузька декоративна крайка та таблиця майже на весь аркуш. Остаточний розмір значків — помірний, під назвами: користувач прямо вибрав проміжний зменшений варіант понеділка. Варіанти з надто дрібними значками в рядок не використані.

Усі п’ять сторінок заново згенеровано для Романівського ліцею ім. М. Т. Рильського за перевіреним розкладом І семестру 2026–2027 та дзвінками Почуйків. За основу оформлення взято погоджений стиль Квітневого ліцею. У кожному прийнятому зображенні візуально перевірено всі 49 клітинок, 7 діапазонів часу, назви класів, заголовок і групи.

Файли `*-prompt.txt` та окремі edit-файли документують генерацію. Review JSON фіксує прийнятий оригінал, перевірку та вибір стилю. Невибрані експерименти можуть бути згадані в історії перевірки; вони не є опублікованими PNG.

PNG збережені без зміни. Для друку підготовлені окремі PDF днів та один PDF на 5 аркушів A4. Кожна сторінка містить лише оригінальне зображення, пропорційно вписане без обрізання та додаткових написів, із безпечними полями щонайменше 5 мм. З цих PDF створено PNG для друку з такими самими полями та WebP для швидкого перегляду.
