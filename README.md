# Романівка · Розклад 2026–2027

Розклад **5–11 класів Романівського ліцею ім. М. Т. Рильського**, І семестр 2026–2027 навчального року.

[Відкрити сайт](https://serhii0304.github.io/Rozklad-Romanivka/)

Функціональність і оформлення перенесені з розкладу Квітневого ліцею: загальний день і тиждень, окремі сторінки класів, виділення предметів, кольорові колонки, світла й темна теми, великі таблиці з гортанням на смартфонах, поточний урок або перерва, київський час і відлік до дзвінка. Звуки дзвінків і хвилини мовчання працюють після дозволеної браузером взаємодії зі сторінкою.

Дані звірено 06.10.2026 з файлом «Романівський_ліцей_5–11_класи_А4.pdf» та п’ятьма денними PNG з папки «Романівка/Розклад»: 245 позицій, 215 заповнених і 30 порожніх. Групи 8 класу збережено. Дзвінки точно відповідають розкладу Почуйок: 08:30–15:05, уроки по 45 хвилин; перерви 10, 20, 20, 10, 10, 10 хвилин.

Це продовження репозиторію `Rozklad-final`, перейменованого на `Rozklad-Romanivka`, зі збереженням його історії. Код, налаштування теми, звукові блокування та QR-код належать Романівці. Інші шкільні сайти не змінюються.

## Друк і QR-код

- [Тижні окремих класів](https://serhii0304.github.io/Rozklad-Romanivka/print.html): сім цілісних зображень розкладу, PNG і PDF.
- [Загальний тиждень](https://serhii0304.github.io/Rozklad-Romanivka/week-print.html): п’ять сторінок по днях, окремі файли й спільний PDF.
- [Дзвінки для друку](https://serhii0304.github.io/Rozklad-Romanivka/bells-print.html): синьо-жовте зображення, PNG і PDF.
- [QR-код](https://serhii0304.github.io/Rozklad-Romanivka/qr.html): великий код сайту, повноекранний перегляд і завантаження PNG/SVG.

Текст, таблиці, ілюстрації й фон друкованих розкладів генеруються разом у ImageGen. Прийняті PNG зберігаються без перемальовування. PDF містять лише зображення з полями щонайменше 5 мм; готові PNG для збереження вже містять ці поля. Під час друку PDF вибирайте «Вмістити в область друку».

## Локальний запуск

Для перегляду й тестів потрібен Node.js, без додаткових пакетів:

```sh
npm run dev
npm test
npm run build
```

Локальна адреса: http://localhost:4173/. Збірка у `build/` перевіряє посилання, код, друковані файли, контрольні суми та відповідність маніфестів розкладу. GitHub Pages публікує корінь гілки `main`.

Для виготовлення нових друкованих комплектів потрібні ImageGen, `sharp`, Python з Pillow/ReportLab/pypdf і Poppler. Порядок оновлення, джерела та технічні обмеження — у [SCHEDULE_SETUP.md](SCHEDULE_SETUP.md).
